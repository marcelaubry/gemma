#   Documented resolution if that conflict occurs (AAP §0.7.2):

#     2. Optionally export `ENABLE_PJRT_COMPATIBILITY=1` to permit a newer

#     3. ESCALATE to the user if gemma requires a JAX newer than jax-metal can
#        support — NEVER silently upgrade `jax-metal` itself.

#   forcibly conflicts with the table above; keep `jax` EXACTLY equal to
